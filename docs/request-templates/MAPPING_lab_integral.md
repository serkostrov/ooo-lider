# Маппинг: заявка → бланк лаборатории «Интеграл» (Word)

Образцы: `docs/request-templates/Лаб. Интеграл/*.docx`  
Актуальный бланк просвета: `просвет стыков интеграл.docx`  
Генератор: `lab_integral_docx` → файл `.docx`.

Виды заявок: **Интеграл** (просвет стыков), **АНПИ**, **ДИ** (все уходят в ООО «Интеграл»).

| № в бланке | В бланке | Откуда в CRM |
|------------|----------|--------------|
| — | Исх. № / дата | Поле **«Исх. №»** (офис) или номер заявки; дата — сегодня (МСК) |
| — | Кому | Константа: В лабораторию ООО «Интеграл» |
| 1 | Заказчик | Константа: ООО «ЛИДЕР» |
| 2 | Метод контроля | Поле **«Метод контроля»** (дефолт для Интеграл: Ультразвуковой / Радиографический) |
| 3 | Дата и время | `call_date` + **«Время вызова»** |
| 4 | Нормы | Поле **«Нормы контроля»** (дефолт из образца) |
| 5 | Условия выполнения | Поле **«Условия / виды работ»** (дефолт: просвет стыков на месте) |
| 6 | Объект | `objects.name` |
| 7 | Регистрация проекта в УТН | Поле **«Номер и дата регистрации проекта в УТН»** (офис, необязательно) |
| 8 | Адрес контроля | `objects.address` |
| 9 | Типоразмер / пикеты | **«Типоразмер и пикеты»** + **«Пикеты (от – до)»** |
| 10 | Представитель | **«Ответственный за производство работ»** |
| — | Примечание | Поле заявки (необязательно) |

`request_types.doc_template = 'lab_integral_docx'`.
