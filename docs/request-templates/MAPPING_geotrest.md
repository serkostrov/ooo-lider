# Маппинг: заявка → сообщение Геотрест (Max)

Образец: текст из чата с Миланой (просто сообщение, без Word).  
Генератор: `geotrest_message` → копирование в буфер.

| № | В сообщении | Откуда в CRM |
|---|-------------|--------------|
| 1 | Дата вызова | `call_date` + поле **«Вид вызова»** (дефолт КГС) → «КГС на ДД.ММ.ГГГГ» |
| 2 | Шифр и наименование | Поле офиса **«Шифр и наименование объекта»** или `project_number` + `objects.name` |
| 3 | Коммуникация и объём | Поле **«Коммуникация и объём»** |
| 4 | Адрес | Поле **«Точный адрес для вызова»** или `objects.address` |
| 5 | Ответственный | Поле **«Ответственный на объекте»** |

`request_types.doc_template = 'geotrest_message'`, `send_by_email = false`.
