# Маппинг: заявка → Excel технадзора

Шаблон: `public/templates/technadzor.xlsx`  
Строка данных: **9** (заголовки в строках 7–8).

| Ячейка | В бланке | Откуда в CRM |
|--------|----------|--------------|
| A9 | Время вызова | `requests.call_date` + поле заявки **«Время вызова»** → `ДД.ММ.ГГГГ ЧЧ-ММ` |
| B9 | Инспектор | Объект → контакт «Технадзор» (`technadzor_contact`, ФИО) |
| C9 | Заказчик | Объект → `customer.name` |
| D9 | Строительная организация | Константа `"ЛИДЕР" ООО` |
| E9 | Ответственный за производство работ | Поле заявки **«Ответственный за производство работ»** (дефолт из настроек поля) |
| F9 | Адрес объекта | Объект → `address` |
| G9 | Виды работ | Поле заявки **«Виды работ»** (свободный текст) |
| H9 | № проекта | Объект → `project_number` |
| I9 | Регистрация УТН № | Объект → `utn_number` |
| J9 | Регистрация УТН дата | Объект → `utn_date` |
| K9 | Примечание | Поле заявки **«Примечание»** |

Вид заявки «Технадзор» помечается `request_types.doc_template = 'technadzor_xlsx'`.
